# TimelyMemo - Your external memory

**Remember. Connect. Notice.**

TimelyMemo is an AI-powered personal memory assistant. Tell it anything - purchases,
promises, ideas, books, decisions - and it extracts structure, embeds it for semantic
search, connects related memories, and surfaces what you're likely forgetting.
You never organize anything manually.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS v4
- Supabase (PostgreSQL + pgvector + Auth + RLS)
- Gemini (extraction, chat, embeddings) - server-side only, key never reaches the client
- Web Speech API for microphone capture; PWA + Web Push

## Setup

1. **Node 18.18+ / 20+**, then run:
   npm install
   cp .env.example .env.local

2. **Supabase** - create a project at supabase.com. Run EVERY file in
   supabase/migrations in numeric order in the SQL editor (or "supabase db push").
   Every migration is safe to run again. The most recent ones:
   - 0023_timelymemo_v2.sql - movie/sleep types, Watch agent, Knowledge base,
     Deep Research
   - 0024_book_identity.sql - books are told apart by title AND author
   - 0025_sleep_events_fuzzy_search.sql - bedtime/wake-up tags for sleep totals,
     and typo-tolerant search (installs the fuzzystrmatch extension)
   (If a migration errors on "alter type ... add value" inside a transaction, run
   that line alone first, then the rest.)

3. **Gemini** - get an API key at aistudio.google.com, set GEMINI_API_KEY.

4. **Auth URLs** - Supabase -> Authentication -> URL Configuration:
   - Site URL: your app URL
   - Add <SITE_URL>/auth/callback to Redirect URLs
   - Enable the Google provider if desired, then set NEXT_PUBLIC_GOOGLE_OAUTH_ENABLED=1

5. **Push (optional)** - run "npx web-push generate-vapid-keys", put the keys in
   WEB_PUSH_PUBLIC_KEY / WEB_PUSH_PRIVATE_KEY.

6. **Run** - npm run dev, then open http://localhost:3000. Create an account at /login.

## Background jobs (deploy to Vercel; crons are pre-wired in vercel.json)

All times UTC, once a day (the Vercel Hobby limit):

- /api/cron/daily (03:30) - fires due reminders, re-surfaces snoozed
  notifications, runs insights ("What am I forgetting", "Connect the dots", ...).
- /api/cron/weekly (Mondays 04:00) - weekly AI reflection.
- /api/cron/reprocess (06:30) - sorts notes that were saved while the AI was
  unavailable (spend cap, quota, outage). Also runs after a user's next
  successful capture, and from the admin panel's "Sort them now" button.
- /api/cron/watches (07:00) - checks every active Watch (prices, job
  openings, page changes); stops early if the AI is unavailable.

If Gemini hits its spending cap or quota, users see a friendly "AI is paused"
message (saving notes keeps working), every admin gets a notification, and the
admin panel shows a red AI-health banner with a link to fix it.

All crons require the x-cron-secret header (or ?secret=) matching CRON_SECRET.

## How memory works

- **Original text is immutable.** AI metadata lives in memory_metadata alongside it.
- Every memory gets a 768-dim embedding (Gemini, retrieval-task-tuned) stored in pgvector
  with an HNSW index.
- Search/chat use a hybrid SQL function (hybrid_search): full-text + vector + filters,
  RLS-scoped, RRF-style scoring.
- Capture-time similarity >= 0.86 cosine triggers "You said this before".
- Insights are generated by deterministic algorithms over embeddings + counts; the LLM
  only names clusters. Every insight keeps source_memory_ids for "Why am I seeing this?".

## Books

Say "I finished Atomic Habits by James Clear" - extraction classifies it as a book
memory, creates/advances a shelf entry (status only moves forward), links the original
memory, and keeps authors out of your People list (recommenders DO appear there).
The shelf at /books is editable: status, 1-5 stars. "+ Add a book" prefills capture.

## Privacy & security

- RLS on every table, owner-only policies (auth.uid() = user_id).
- All Gemini calls are server-side; the key never reaches the browser.
- AI output is Zod-validated before any DB write; no arbitrary SQL from AI.
- DELETE /api/account hard-deletes the auth user; FK cascades remove all data.
- GET /api/account exports everything as JSON.
- Memories are never used for model training.

## Troubleshooting

- **First build is the integration test.** If hybrid_search fails, run it once in the
  SQL editor with test params to see the raw Postgres error.
- Capture saves even when extraction fails (status "failed" in memory_metadata) -
  check the server logs for the Gemini error.
- Push button says "not configured" until VAPID keys are set - by design, no fake buttons.
- Add 192/512 PNG icons next to icon.svg for wider PWA install support.
